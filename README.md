# ERP Marketplace - GitHub Pages

Esta pasta esta pronta para publicar online como site estatico.

## Publicar no GitHub Pages

1. Cria um repositorio no GitHub.
2. Faz upload de todo o conteudo desta pasta, incluindo `index.html` e a pasta `etiquetas/`.
3. No repositorio, abre Settings > Pages.
4. Escolhe Deploy from a branch, branch main, pasta /root.
5. O site fica disponivel em `https://<utilizador>.github.io/<repositorio>/`.

## Privacidade

Este ERP inclui nomes de compradores, estados de encomendas, valores e etiquetas PDF. Usa um repositorio privado ou um servico com acesso protegido se nao quiseres expor estes dados publicamente.
